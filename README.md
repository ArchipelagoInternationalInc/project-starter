# Archipelago Studio Kit — version 3

Effective October 30, 2026 — ratified by Scott. The change record is `KIT_V3_CHANGES.md`.

The seven numbered files at the top of this repository are the studio's complete standing rules:

- `01_HOW_WE_WORK.md` — who does what, including the Studio Head (Claude Duet), cloud Builders, and Madelyn's seat
- `02_STARTING_AND_RUNNING_A_PROJECT.md` — the Builder's rulebook and the six anchor files
- `03_WHAT_WE_SAY_IN_PUBLIC.md`
- `04_OUR_TOOLS.md`
- `05_THE_PORTFOLIO_RULES.md` — the lineup tiers and the four layers of truth
- `06_THE_UNATTENDED_LOOP.md` — how Builders run without anyone clicking "allow"
- `07_HOW_WE_CHOOSE.md` — the Market Brief law for new products

If a rule isn't in these seven files, it isn't a rule.

`PLATFORM_REFERENCE_CARD.md` sits alongside them as a companion reference, not a rules file. It records the platform traps the studio has already paid for, so no project pays that tuition twice.

Templates for the anchor files and the loop: `GOAL_TEMPLATE.md`, `INBOUND_TEMPLATE.md`, `DECISIONS_TEMPLATE.md`, `DEFINITION_OF_DONE_TEMPLATE.md`, `settings.template.json`, `verifier.template.md`, `verify.template.sh`. `CONVERSION_KIT.md` moves an existing project onto the loop.

The studio's perishable state — the lineup, the status board, the decision lists — lives in the separate `studio-hq` repository, not here. This repository changes only when a rule changes.

`STUDIO_KIT_V2_REVISION_NOTES.md` is the September 2026 field review of version 2; its findings are folded into version 3 and it is kept as the record of why.

`archive/` holds superseded documents: the version 1 files, and under `archive/OLD/` the earlier Starter Kit 00–08 drafts and amendments recovered from the PR Mac. Nothing in `archive/` is in force.

`project-kickoffs/` is not part of the kit. It holds planning documents for individual projects.

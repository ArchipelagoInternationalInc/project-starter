# Archipelago Studio Kit — version 2

Effective August 2026.

The five numbered files at the top of this repository are the studio's complete standing rules:

- `01_HOW_WE_WORK.md`
- `02_STARTING_AND_RUNNING_A_PROJECT.md`
- `03_WHAT_WE_SAY_IN_PUBLIC.md`
- `04_OUR_TOOLS.md`
- `05_THE_PORTFOLIO_RULES.md`

If a rule isn't in these five files, it isn't a rule.

`PLATFORM_REFERENCE_CARD.md` sits alongside them as a companion reference, not a rules file. It records the platform traps the studio has already paid for, so no project pays that tuition twice.

`07_HOW_WE_CHOOSE.md` (the Market Brief law, September 2026) and `STUDIO_KIT_V2_REVISION_NOTES.md` (the SendMyLicense Builder's review of this kit, 16 September 2026) are filed here for ratification into Kit version 3. Until that ratification is recorded, the five numbered files above remain the rules.

`archive/` holds the superseded version 1 documents and, under `archive/OLD/`, the earlier Starter Kit 00–08 drafts and amendments recovered from the PR Mac. They are kept as history, not as trash — and not as rules. Nothing in `archive/` is in force.

`project-kickoffs/` is not part of the kit. It holds planning documents for individual projects.
